# MASHS 2023--2024: ideal food system

**Status:** `validated` for the offline package and preview checks
**NaileR object:** `mashs_food_system`
**Source:** local MASHS/don_clust.rData

## Scientific identity

This study concerns opinions about an ideal food system and used a Q-sort-like
questionnaire protocol. The retained statistical route is an MCA followed by
HCPC. It must not be described as a classical Q-method factor extraction, and
it must not be confused with the `quality` study on food logos.

The source table contains 573 rows, 60 categorical questionnaire responses,
three demographic variables and a four-level constructed group identifier.
The package object retains the 60 response variables and the group identifier.
The demographic columns are excluded from the distributed object to avoid
unnecessary quasi-identifying information. Group sizes are 226, 113, 116 and
118.

## Reconstruction

The source analysis used response columns 1:45 as active MCA variables and
later questionnaire responses as supplementary variables. The group
identifier is retained without replacing it by substantive profile names.
The package example calls `nail_catdes(..., generate = FALSE)` and inspects
the evidence and prompt through public accessors.

The source workspace contains no direct identifiers in the selected table.
The object is therefore suitable for package distribution subject to the
project's final data-rights record. The data are reported opinions, not
observed behaviour or causal measurements.

## Reproducibility

Run from the repository root:

    Rscript dev/transition_reconstruction/build_mashs_irtsat_data.R

Set `NAILER_MASHS_QSORT_RDATA` to use another source location. The script
checks dimensions, missingness, the absence of an `ID` column and group sizes
before writing `data/mashs_food_system.rda`.

## Remaining scientific reserve

The four group identifiers are preserved as constructed labels. The
descriptive names reported in historical documents are not embedded in the
data object, because their exact mapping to numeric group labels is not needed
for the statistical contract and should not be silently reinterpreted.
