## Sources and executed analyses

SPISE and Distinction are names used for the same 2025--2026 study; this file
describes the SPISE working subset rather than a separate survey. The project
directory is `/Users/sebastienle/Documents/2025-2026/Spise/`. The principal
input is `data/Bretons.xlsx`, 182 × 81, with 48 Likert items and context
variables. The distributed teaching object is built from the documented
`data/Bretons_no_NA.xlsx` derivative (181 rows) and contains only the 48 item
responses. Its audited SHA-256 is
`04a430c6f8a8e4e36954fea414a264a494c67b7a0129eb455686fd5bfc23d5be`.
`data/Bretons_no_NA.xlsx` is a derived 181-row file.

The project contains executed diagnostic scripts, GRM/mirt model registries,
item parameters, fit and information outputs, local-dependence diagnostics,
scores and an MFA-versus-IRT comparison. The six named blocks are origin,
procurement, territorial anchoring, seasonality/ecology, accessibility/
solidarity, and civic engagement. A tutorial also contains a five-item GRM,
which is pedagogical and must remain separate from the survey result.

## NaileR route

The distributed item table is suitable for inspection and for preparing a
documented score analysis. Once a selected model and score table are frozen,
use `nail_condes(..., interpretation_mode = "latent", generate = FALSE)`.
`nail_catdes()` can follow only after a canonical classification is selected.
The scores are latent estimates, not observed behaviour and not a global
commitment scale by default. The package does not invent either score or
classification for the item object.

## Open points

The relation between this subset and the Distinction/Survey exports is known
at the study level, but the source-level row selection, recoding, package
versions and final latent-model decision are not all frozen. No model is rerun
by the repository validation script. The distributed item object is therefore
an educational instrument export, not a claim that a final latent score or
classification has been established.
