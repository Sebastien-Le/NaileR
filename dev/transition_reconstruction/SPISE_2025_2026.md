## Sources and executed analyses

Project: `/Users/sebastienle/Documents/2025-2026/Spise/`. The principal
input is `data/Bretons.xlsx`, 182 × 81, with 48 Likert items and context
variables. Its audited SHA-256 is
`04a430c6f8a8e4e36954fea414a264a494c67b7a0129eb455686fd5bfc23d5be`.
`data/Bretons_no_NA.xlsx` is a derived 181-row file.

The project contains executed diagnostic scripts, GRM/mirt model registries,
item parameters, fit and information outputs, local-dependence diagnostics,
scores and an MFA-versus-IRT comparison. The six named blocks are origin,
procurement, territorial anchoring, seasonality/ecology, accessibility/
solidarity, and civic engagement. A tutorial also contains a five-item GRM,
which is pedagogical and must remain separate from the survey result.

## NaileR route

Once the extraction rule, item dictionary and selected model are frozen, use a
score table with `nail_condes(..., interpretation_mode = "latent",
generate = FALSE)`. `nail_catdes()` can follow only after a canonical
classification is selected. The scores are latent estimates, not observed
behaviour and not a global commitment scale by default.
