## Reconstructed route

The analysis reads columns 3:50 as 48 five-level ordered items, arranged in
six blocks of eight. It fits `mirt(..., itemtype = "graded")`, obtains
`fscores()`, rescales the scores, and uses `set.seed(123)` before a visible
three-centre k-means. The six block labels are imposed by item order in the
script and are not, by themselves, proof of six empirical factors.

## NaileR object and controls

The future final object should be a de-identified data frame containing the
individual or aggregate validated IRT score(s), the frozen group identifier,
and only descriptors authorised for interpretation. Candidate routes are
`nail_condes(..., interpretation_mode = "latent", generate = FALSE)` for a
score and `nail_catdes(..., interpretation_mode = "latent", generate = FALSE)`
for the class table. `nail_evidence()` and `nail_prompt()` are the required
audit accessors.

## Open points

of the scientifically retained four groups are not linked by a single
reproducible script. A three-centre output must not be relabelled as the
