# IRTSAT 2024--2025

**Status:** `validated` for the offline package and preview checks
**NaileR object:** `irtsat_2024_2025`
**Source:** local IRTSAT `.RData` workspace

## Scientific identity

The scientifically retained typology has four groups:

- Territorially disengaged;
- Distant consumers;
- Pragmatic involved consumers;
- Territorial activists.

The visible `analyse_irt_multidim.Rmd` script contains a three-centre k-means
illustration. That result is not used as the final classification and is not
renamed as the four-group decision.

## Frozen export

The package object `irtsat_2024_2025` contains 529 rows, one frozen numeric
`IRT_score`, 34 categorical descriptors and the four-level `profile`
identifier. All rows are assigned to one of the four profiles; the group sizes
are 83, 180, 179 and 87 in the documented factor order. The score and
descriptors are aligned by their original row order in the retained workspace.
No personal identifier is distributed.

The package object `irtsat_items_2024_2025` is a separate 541-row export of
the 48 Likert assertions used by the IRT analysis. It has 48 ordered factor
columns, 14 missing item responses, six blocks of eight items, English
variable names and English response levels. The exact French questionnaire
wording is recorded in `IRTSAT_48_ITEMS_DICTIONARY.csv`; it is retained as
instrument provenance rather than silently rewritten. Timestamp, region and
other complementary fields are omitted.

The 541-row item export and the 529-row profile export have no validated common
row key. They are both usable as independent teaching resources, but must not
be joined by row order.

The raw `data_536.csv` contains 536 rows. Seven rows are absent from the
frozen 529-row analysis table; no replacement assignment is invented. The
package object is therefore a frozen analysis export, not a claim that the
current three-centre script can regenerate the final typology.

## NaileR routes

Use `nail_catdes(..., num.var = ncol(irtsat_2024_2025), generate = FALSE)` to
characterize the four profiles. Use `nail_condes()` on a copy without
`profile` to characterize the IRT score without circularly using the class
assignment as a descriptor. Inspect `nail_evidence()` and `nail_prompt()`
before any generation. Inspect `irtsat_items_2024_2025` as an instrument;
because it has no grouping variable or derived score, do not pass it to
`nail_catdes()` without an external documented grouping decision.

## Reproducibility

Run from the repository root:

    Rscript dev/transition_reconstruction/build_mashs_irtsat_data.R

Set `NAILER_IRTSAT_WORKSPACE` or `NAILER_IRTSAT_ITEMS_CSV` to use another
source location. The script checks the 529-row descriptor table, the 529
matching finite scores, the absence of missing values and the four profile
counts before writing `data/irtsat_2024_2025.rda`. It separately checks the
541-row, 48-item export and writes `data/irtsat_items_2024_2025.rda` plus its
English dictionary.

## Remaining scientific reserve

The item-level IRT model settings, diagnostics and the exact derivation of the
frozen four-group export are not fully reconstructed by the visible
three-centre script. The published object preserves the available score and
assignment without claiming a new IRT fit.
