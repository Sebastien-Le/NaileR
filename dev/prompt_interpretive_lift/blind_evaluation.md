# NaileR interpretive-lift — Blind evaluation

Evaluation performed before consulting the X/Y condition key.

## Scoring convention

For Interpretive value, Grounding / traceability, Calibration, Synthesis, and Unsupported overreach control:

- 0 = insufficient
- 1 = acceptable / minor weakness
- 2 = convincing

For **Unsupported overreach**, a higher score means that unsupported overreach is **better controlled**:
- 0 = problematic overreach
- 1 = minor or qualified overreach
- 2 = no material overreach

For **Paraphrase tendency**:
- 0 = low
- 1 = moderate
- 2 = high
