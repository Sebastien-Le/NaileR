# C02 shareable validation bundle

This bundle contains the reproducible offline script, aggregate audits,
CATDES evidence, prompts and statistical reference objects for
`atomic_habit_clust`.

It intentionally excludes the original questionnaire data, all open-ended
responses, and any individual-level text. The local directory one level above
contains the complete offline artifacts, including previews and detailed text
counts.

No LLM call was made. The case remains `ready_for_validation`; this bundle is
not a semantic validation of generated interpretations.
